Selection indicator

Corner ticks

Four short brackets at the selection's corners, clamped to the view, over a barely-there tint.

1. On screen
Fits comfortably inside the view
2. Partly off screen
Runs past one edge
3. Huge, partly visible
One edge inside, the rest far off
4. Covers the view
No edge on screen at all

How it is built

The same clamp as the frame option, but only eight line segments are ever drawn.

Why choose it

The quietest option, and the closest to the sketchbook feel. It marks the corners the way a crop guide would.

What to watch

In case 4 the ticks sit in the view's own corners, which can read as interface chrome rather than as the object.

Object shimmer

The object carries its own state. Its silhouette breathes and it takes a soft terracotta wash, with no bounding box anywhere.

1. On screen
Fits comfortably inside the view
2. Partly off screen
Runs past one edge
3. Huge, partly visible
One edge inside, the rest far off
4. Covers the view
No edge on screen at all

How it is built

The silhouette is clipped to the viewport, and the animation drives stroke opacity and fill opacity only.

Why choose it

Size-independent by construction. Case 4 reads exactly as well as case 1, which no box-based option manages.

What to watch

Animating anything other than opacity on a large fill risks a repaint per frame. Opacity composites; geometry does not.
